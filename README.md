# Elaborando-Um-Quiz
Este projeto é uma elaboração de um quiz para a aula do professor Anderson da faculdade Unicesumar. Nele faremos um diagrama e código em java para a criação do jogo.
#### Feito por Pedro Bezerra e Gabriel Alves

## Como jogar o quiz?

Para jogar nosso quiz, basta clonar o repositório no seu computador local seguindo o passo a passo abaixo:
1. Acesse o GitHub e entre no repositório que deseja baixar.
2. Clique no botão verde "Code" e copie a URL HTTPS.
3. Abra o Visual Studio Code no seu computador.
4. Pressione as teclas Ctrl + Shift + P para abrir a paleta de comandos.
5. Digite "Git: Clone" e selecione essa opção na lista.
6. Cole a URL que você copiou do GitHub e aperte Enter.
7. Escolha uma pasta no seu computador onde o projeto será salvo.
8. Clique em Abrir (ou Open) na mensagem que aparece no canto inferior direito para começar a usar o projeto.

### Compile o código

Talvez seja necessário compilar o código para que seja iniciado pelo terminal. Utilize esses comandos para compilação e iniciação do código no terminal do VScode:

<pre>
  javac main.java // Para compilar
  java main.java // Para iniciar
</pre>
